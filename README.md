# Selected Records

RWD portfolio prototype built with HTML, CSS and JavaScript.

## Preview locally

Run `python3 -m http.server 8000` in this folder, then open http://localhost:8000.

## Files

- `index.html`: page structure and Web / Visual / Motion tabs.
- `style.css`: responsive layout, typography and animation.
- `projects.js`: base project data.
- `app.js`: sliders, project popups, lightbox and scrolling; also includes Visual and Motion demo data.
- `assets/`: existing image, locally bundled Lenis and its license.

## Current content

Web: 10 projects. Visual: 10 works. Motion: 8 groups. This is a prototype: many artwork blocks are placeholders and Motion videos have not been supplied yet.

## Hosting

This is a static site with no build step. The publish directory is the repository root (`.`). Hosting has not been enabled by this import.
